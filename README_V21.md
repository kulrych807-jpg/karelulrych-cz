# v21 – finální profesionální opravy před ostrým provozem

Tento balíček je bezpečný patch. Nenabourává strukturu webu.

Nahrajte na GitHub pouze obsažené soubory a potvrďte Commit changes.

## Opraveno
- Kontakt / objednávka: jednoduchý mailto formulář bez Make, Web3Forms, SMTP a Google Sheets.
- Veřejné technické sliby o Make / Google Sheets / AI třídění odstraněny z objednávkového procesu.
- Výklad karet: každý výklad má samostatný blok, mezeru mezi popisem, cenou a tlačítkem.
- Obchodní podmínky a GDPR: odstraněn překlep „poptávkya“ a zpřesněn text objednávky.
- Reiki: zjemněno na „Reiki harmonizace“.
- Certifikát: ponechána stránka se dvěma certifikáty včetně postgraduálního certifikátu.
