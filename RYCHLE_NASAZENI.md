# Rychlé nasazení v14

1. Rozbalte ZIP.
2. Nahrajte celý obsah na GitHub do repozitáře `karelulrych-cz`.
3. Potvrďte `Commit changes`.
4. Ve Vercelu počkejte na stav `Ready`.
5. Ověřte:
   - https://www.karelulrych.cz
   - https://www.karelulrych.cz/o-mne.html
   - https://www.karelulrych.cz/kontakt.html
   - https://www.karelulrych.cz/obchodni-podminky.html
   - https://www.karelulrych.cz/ochrana-osobnich-udaju.html

Pro ostré odesílání formuláře doplňte Web3Forms Access Key v `kontakt.html`.
